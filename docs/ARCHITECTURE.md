# System Architecture & Design Specification

## Overview

CollabCode is structured around modular, loosely-coupled layers designed for high concurrency, real-time collaboration, and isolated code execution:

```
┌────────────────────────────────────────────────────────┐
│               Frontend: Vite + React 19                │
│   Monaco Editor │ Project Explorer │ AI Panel │ Docks  │
└───────────────────────────┬────────────────────────────┘
                            │ HTTP (REST) / WebSockets (Collab)
                            ▼
┌────────────────────────────────────────────────────────┐
│            API Gateway: Express / Node.js              │
│   Auth / RBAC │ Project Manager │ AI Context Aggregator│
└─────────────┬───────────────────────────┬──────────────┘
              │                           │
              ▼                           ▼
┌──────────────────────────┐    ┌─────────────────────────┐
│     SQLite Relational    │    │ Execution Service       │
│  Projects, Files, Users  │    │ ┌─────────────────────┐ │
│  Audit Logs & Executions │    │ │ Language Registry   │ │
│  WAL Mode, Indices       │    │ └──────────┬──────────┘ │
└──────────────────────────┘    │            ▼            │
                                │ ┌─────────────────────┐ │
                                │ │ Sandboxed Worker /  │ │
                                │ │ Container Runner    │ │
                                │ └─────────────────────┘ │
                                └─────────────────────────┘
```

## Core Subsystems

### 1. Frontend Client
- **Monaco Editor Component**: Encapsulates code editing with AST-level IntelliSense, multi-cursor, bracket matching, and theme synchronization.
- **State Orchestration**: Handles project switching, active file buffers, unsaved changes tracking, and debounced autosave.
- **Visual Diff Viewer**: Computes and renders unified diffs generated by the AI assistant before code is inserted into the editor.
- **Click-to-Line Navigation**: Bridges output diagnostics with Monaco editor cursor positioning.

### 2. Backend API & WebSockets
- **Express API Gateway**: Manages authentication, project CRUD, file transactions, and code execution dispatch.
- **WebSocket Collaboration Server (`CollabServer`)**: Handles room-based multiplexing (`/ws?projectId=xxx`), broadcasting active presence, live cursor tracking, and team messages.

### 3. Unified Execution Engine
- Follows the adapter pattern:
  ```
  Language -> Compiler/Runtime Adapter -> Execution Worker -> Result
  ```
- Supports dual execution models:
  1. Isolated Container/Worker API with execution timeouts and memory bounds.
  2. Local Sandboxed Worker fallback using isolated temporary directories and child process sandboxing.
  3. Safe In-Memory SQLite runner for SQL query execution.
  4. Client/Server HTML/CSS web playground renderer.

### 4. AI Collaboration Subsystem
- **Context Builder**: Gathers the minimal required context hierarchy:
  `User -> Project -> Active File -> Selected Code -> Compiler Output -> Conversation History`
- **Semantic Code Reasoning Engine**: Performs AST analysis, syntax fixes, optimizations, documentation generation, refactoring, and code review without depending solely on external third-party keys.
- **External LLM Bridges**: Direct integrations with Google Gemini and OpenAI when API keys are configured.
